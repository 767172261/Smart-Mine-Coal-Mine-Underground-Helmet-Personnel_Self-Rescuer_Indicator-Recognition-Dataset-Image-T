| 信息类别       | 具体内容                                                                 |
|----------------|--------------------------------------------------------------------------|
| 数据集类别     | 计算机视觉领域下的目标检测数据集，包含5个核心检测类别：helmet（头盔）、indicator（指示器）、person（人员）、self-rescuer（自救器） |
| 数据数量       | 包含4369张图像，对应3个子数据集，已训练1个目标检测模型                   |
| 数据格式       | 支持图像文件上传检测（支持拖放或本地文件浏览上传），适配目标检测模型输入需求 |
| 核心应用价值   | 可用于矿山、工业场景下的安全监测，如人员识别、安全装备（头盔、自救器）佩戴检查、设备指示器状态监测，助力场景安全自动化管理 |

该数据集属于目标检测类计算机视觉数据集，聚焦特定场景下的关键目标识别。核心覆盖5个实用类别，既包含人员这类主体目标，也涵盖头盔、自救器等安全装备，还纳入了指示器这类设备部件，类别设置贴合实际场景安全监测需求。

从数据规模来看，数据集包含4369张图像，数量充足且划分成3个子数据集，能为模型训练提供多样样本支撑。基于这些数据已构建1个目标检测模型，可直接用于相关目标的检测任务，减少模型训练的基础数据准备成本。

数据集在应用层面具有明确的场景指向性，核心价值集中在安全监测领域。通过检测人员、安全装备及设备指示器，可实现对矿山等工业场景的实时安全管控，帮助及时发现未佩戴安全装备、设备异常等问题，推动场景安全管理向自动化、智能化转型。
